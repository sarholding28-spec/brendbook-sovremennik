# Presentation style package — ЖК «Современник»

Этот комплект предназначен для хранения в репозитории брендбука ЖК «Современник».

## Рекомендуемое размещение

```text
docs/
├── PRESENTATION_STYLE_GUIDE.md
└── presentation-style-tokens.json
```

## Назначение файлов

- `PRESENTATION_STYLE_GUIDE.md` — подробное руководство по композиции, типографике, цветам, фото, плашкам и правилам доработки слайдов.
- `presentation-style-tokens.json` — краткая машинно-читаемая сводка ключевых параметров.

## Как использовать

При создании или редактировании презентаций ЖК «Современник» сначала сверяться с:
1. брендбуком и логотипами в репозитории;
2. `PRESENTATION_STYLE_GUIDE.md`;
3. эталонной презентацией.

Новые слайды должны выглядеть как естественное продолжение исходной презентации.
