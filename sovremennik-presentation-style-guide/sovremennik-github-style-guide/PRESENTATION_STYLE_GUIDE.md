# ЖК «Современник» — руководство по композиции и оформлению презентаций

## Статус документа

Этот файл фиксирует визуальные принципы презентации  
**«современник преза в печать для агентств»**  
и используется как рабочее руководство при создании и доработке новых слайдов ЖК «Современник».

Главная цель: новые слайды должны выглядеть так, будто они были сделаны тем же дизайнером и в рамках той же визуальной системы.

---

# 1. Источник истины

При создании и редактировании материалов ЖК «Современник» использовать как приоритетные источники:

1. Репозиторий бренда:
   `https://github.com/sarholding28-spec/brendbook-sovremennik`

2. Эталонную презентацию:
   `современник преза в печать для агентств.pdf`

3. Фирменные материалы, логотип, цвета и шрифты из репозитория.

Важно: стиль ЖК «Современник» и стиль ГК САР — разные визуальные системы.  
**Не смешивать их**, если пользователь явно этого не просит.

---

# 2. Общий принцип композиции

Презентация строится на сочетании:

- большого количества воздуха;
- крупной архитектурной фотографии;
- коротких текстовых блоков;
- лаконичных цветных плашек;
- строгой асимметричной композиции.

На одном слайде обычно есть один доминирующий визуальный объект:

- крупное фото;
- схема;
- план;
- карта;
- цветное поле.

Текст не должен заполнять весь слайд.

Типичное соотношение:
- текст: 25–35%;
- фото / схема: 60–70%;
- свободное пространство: обязательно.

---

# 3. Типовые композиционные схемы

## Схема A — текст слева / фото справа

Самый характерный формат.

Структура:
- белая колонка слева;
- заголовок;
- короткий вводный текст;
- список преимуществ;
- крупное фото справа.

Рекомендуемая пропорция:
- текстовая зона: 30–40%;
- фото: 60–70%.

Использовать как базовый шаблон для информационных слайдов.

---

## Схема B — большое фото + небольшая плашка

Фото занимает основную часть страницы.

Плашка:
- небольшая;
- прямоугольная;
- расположена в верхней или средней трети;
- может частично заходить на фото.

Подходит для:
- фасадов;
- входных групп;
- детских площадок;
- лифтов;
- архитектурных деталей.

---

## Схема C — фирменный фон + схема

Основной фон:
- фирменный фиолетовый.

На нём:
- белая схема;
- бирюзовые акценты;
- белые подписи;
- тонкие линии.

Подходит для:
- планов;
- карт;
- схем инфраструктуры;
- функциональных диаграмм.

---

## Схема D — каталог / планировки

Фон:
- белый.

Композиция:
- строгая сетка;
- много воздуха;
- планировки без декоративных карточек;
- подписи на бирюзовых прямоугольных плашках.

---

# 4. Фирменные цвета

Использовать только фирменную палитру.

## Основные цвета

- `#4A4492` — основной фиолетовый
- `#9D97CA` — светлый фиолетовый
- `#44BABC` — бирюзовый
- `#49C1F0` — голубой
- `#FFFFFF` — белый

---

# 5. Цвета по назначению

## Заголовки

Основной цвет заголовков на белом фоне:

`#4A4492`

Использовать для:
- названий слайдов;
- вводных фраз;
- основных смысловых заголовков.

---

## Бирюзовый

`#44BABC`

Использовать для:
- акцентных плашек;
- иконок;
- подзаголовков;
- маркеров;
- коротких смысловых акцентов;
- подписей планировок.

Не использовать как основной цвет длинного текста.

---

## Голубой

`#49C1F0`

Использовать дозированно:
- вторичные акценты;
- отдельные элементы инфографики;
- линии;
- вспомогательные графические элементы.

---

## Светлый фиолетовый

`#9D97CA`

Использовать:
- как фон второго уровня;
- для вторичных картографических и графических элементов;
- как мягкий вспомогательный цвет.

---

# 6. Шрифты

Основной шрифт:
**TT Norms Medium**

Использовать шрифты из репозитория бренда.

## Заголовки

Принципы:
- TT Norms Medium;
- визуально плотный, но не тяжёлый;
- без декоративных эффектов;
- короткие;
- обычно 1–3 строки;
- без чрезмерного капслока.

Не использовать:
- жирный тяжёлый Bold;
- декоративные шрифты;
- случайные альтернативные гарнитуры.

---

## Основной текст

- нейтральный гротеск;
- тёмно-серый / чёрный;
- короткие абзацы;
- хорошая межстрочная дистанция;
- не перегружать объёмом.

---

## Служебные подписи

Характерная деталь презентации:
- маленький кегль;
- увеличенный трекинг;
- вертикальная подпись `ЖК СОВРЕМЕННИК`;
- номер страницы у края.

---

# 7. Иерархия текста

Использовать 4 уровня.

## Уровень 1 — заголовок

- основной фиолетовый;
- самый заметный текстовый элемент.

## Уровень 2 — подзаголовок / смысловой акцент

- бирюзовый или фиолетовый;
- короче основного текста;
- может быть капсом.

## Уровень 3 — основной текст

- чёрный / тёмно-серый;
- короткими блоками.

## Уровень 4 — техническая информация

- маленький размер;
- номер слайда;
- вертикальная подпись;
- служебные пояснения.

---

# 8. Плашки

Плашки — одна из ключевых частей визуального языка.

## Общие правила

Плашки:
- прямоугольные;
- без скруглений или с минимально заметными;
- без теней;
- без градиентов;
- без 3D;
- без эффекта стекла;
- без свечения.

---

## Фиолетовая плашка

Цвет:
`#4A4492`

Текст:
- белый;
- короткий;
- 1–3 строки.

---

## Бирюзовая плашка

Цвет:
`#44BABC`

Использовать для:
- коротких смысловых фраз;
- второго акцента;
- подписей;
- навигационных элементов.

---

# 9. Принцип расположения плашек

Плашки размещаются осмысленно, а не случайно.

Типовые положения:
- у левого края композиции;
- на стыке белого поля и фотографии;
- в верхней трети;
- частично поверх фотографии.

Характерный приём:
**плашка частично выходит из текстовой зоны на фотографию.**

---

# 10. Работа с фотографиями

Фотография — основа композиции.

## Фото должно быть крупным

Предпочтительно:
- 1 крупное фото;
- либо 1 крупное + 2 небольших.

Избегать:
- множества маленьких изображений;
- карточной сетки без необходимости.

---

## Фото без декоративной обработки

На обычных продуктовых слайдах:
- натуральные цвета;
- нормальная яркость;
- естественный контраст;
- без цветных фильтров;
- без синей или фиолетовой тонировки.

---

## Кадрирование

- строгие прямоугольники;
- геометрически чистое кадрирование;
- фото часто доходит до края слайда;
- без рамок;
- без декоративных теней.

---

# 11. Когда допустима фиолетовая тонировка фото

Фиолетовая тонировка используется только для специальных типов слайдов:

- обложка;
- финальный слайд;
- карта;
- собственная УК;
- специальные разделительные страницы.

Не использовать фиолетовый фильтр на обычных продуктовых фотографиях без необходимости.

---

# 12. Белая колонка + фото

Один из основных шаблонов.

Схема:

| Белая колонка | Фото |
|---|---|
| заголовок | |
| текст | |
| преимущества | |

Белая колонка должна быть визуально лёгкой и не перегруженной.

---

# 13. Иконки

Использовать:
- простые контурные пиктограммы;
- тонкая линия;
- одинаковый размер;
- фирменный бирюзовый.

Характерный элемент:
- маленький круг;
- галочка внутри.

Не использовать:
- эмодзи;
- объёмные иконки;
- разноцветные пиктограммы;
- случайные библиотечные стили.

---

# 14. Разделительные элементы

Использовать:
- тонкие вертикальные линии;
- короткие бирюзовые штрихи;
- тонкие рамки;
- небольшие геометрические разделители.

Они должны структурировать, но не перетягивать внимание.

---

# 15. Правая служебная зона

На многих слайдах используется:
- вертикальная линия;
- вертикальная подпись `ЖК СОВРЕМЕННИК`;
- номер слайда.

При создании новых слайдов в серии этот приём нужно сохранять, если он присутствует в соседних страницах.

---

# 16. Воздух и поля

Ключевой принцип:
**лучше убрать один элемент, чем добавить лишний.**

Допустимо, чтобы 30–40% белого слайда оставалось визуально свободным.

Не заполнять пустоту декоративными элементами.

---

# 17. Оформление планировок

Для слайдов с планировками:

- белый фон;
- заголовок сверху слева;
- строгая сетка;
- планировки без карточек;
- толстые стены / графика — фирменный фиолетовый;
- подпись — на бирюзовом прямоугольнике;
- много воздуха между объектами.

Пример подписи:

```text
2К
57,6 м²
```

Белый текст на фоне `#44BABC`.

---

# 18. Карты и схемы

Если карта стилизованная:

Основной фон:
`#4A4492`

Дополнительные цвета:
- белый;
- `#44BABC`;
- `#49C1F0`.

Не использовать обычную цветную Google / Яндекс-карту, если задача — сохранить единый стиль презентации.

---

# 19. Стиль текста

Тон:
- спокойный;
- архитектурный;
- уверенный;
- лаконичный.

Подходящие формулировки:
- «Стиль и качество в каждой детали»
- «Машине комфортно — вам спокойно»
- «Мир на ладони»

Не использовать:
- агрессивные рекламные призывы;
- чрезмерные восклицания;
- крикливые формулировки;
- визуальный язык масс-маркета.

---

# 20. Что нельзя делать

Запрещено без отдельного указания:

- использовать фирменный синий ГК САР;
- использовать красные линии из корпоративных презентаций САР;
- смешивать типографику ГК САР и Современника;
- использовать градиенты;
- использовать тени;
- использовать 3D-карточки;
- использовать glassmorphism;
- использовать тёмно-синие корпоративные фоны САР;
- использовать золото;
- перегружать слайд иконками;
- помещать весь контент в одинаковые карточки;
- заменять логотип Современника логотипом САР.

---

# 21. Базовая формула нового слайда

Если нужно сделать новый слайд для этой презентации:

- фон: белый;
- заголовок: TT Norms Medium;
- цвет заголовка: `#4A4492`;
- основной акцент: `#44BABC`;
- второй акцент: `#49C1F0`;
- фото: крупное, натуральное, без фильтров;
- композиция: асимметричная;
- текст: 25–35% площади;
- фото: 60–70% площади;
- плашки: прямоугольные, без теней;
- иконки: тонкие, бирюзовые;
- воздух: обязательно;
- вертикальная служебная зона: сохранять, если она есть в серии;
- логотип: только официальный из репозитория;
- стиль ГК САР: не использовать.

---

# 22. Правило доработки существующих слайдов

Если пользователь пишет:

**«Оставь всё неизменным, только…»**

необходимо менять только явно указанные элементы.

Нельзя самовольно:
- менять композицию;
- менять цвета;
- менять шрифты;
- менять размеры;
- менять положение элементов;
- заменять фотографии;
- менять кадрирование;
- добавлять новые элементы.

---

# 23. Контрольный чек-лист перед финальной выдачей

Перед выдачей нового или изменённого слайда проверить:

- [ ] Использован стиль именно ЖК «Современник»
- [ ] Нет элементов визуального стиля ГК САР
- [ ] Заголовки выполнены фирменным фиолетовым
- [ ] Использованы только фирменные акцентные цвета
- [ ] Фото крупное и естественное
- [ ] Нет случайных фильтров
- [ ] Нет теней и градиентов
- [ ] Плашки прямоугольные и лаконичные
- [ ] Есть достаточное количество воздуха
- [ ] Иконки тонкие и однотипные
- [ ] Сохранена визуальная логика соседних слайдов
- [ ] Служебные подписи и номер слайда оформлены в общей системе
- [ ] Логотип взят из репозитория
- [ ] Слайд выглядит как часть исходной презентации, а не как отдельный новый дизайн

---

# 24. Главный визуальный критерий

Новый слайд должен выглядеть так, будто:

**его сделал тот же дизайнер, в тот же период и для той же презентации.**

Использование правильных цветов само по себе недостаточно.  
Нужно сохранять:
- плотность композиции;
- размеры смысловых блоков;
- характер воздуха;
- типографику;
- работу с фото;
- логику плашек;
- ритм и асимметрию.
