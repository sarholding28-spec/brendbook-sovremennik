# ЖК «Современник» — правила фирменного стиля

## Источник истины

Эта папка является рабочим источником фирменного стиля ЖК «Современник» для макетов, презентаций и рекламных материалов.

При запросах вида **«сделай в стиле Современника»** использовать материалы из этой папки как приоритетный источник по:
- логотипу;
- фирменным цветам;
- сочетаниям цветов;
- визуальной идентичности проекта.

## Фирменные цвета

- `#4A4492` — основной фиолетовый
- `#9D97CA` — светлый фиолетовый
- `#44BABC` — бирюзовый
- `#49C1F0` — голубой
- `#FFFFFF` — белый

Точные значения также хранятся в `colors/palette.json`.

## Логотип

Использовать только файлы из папки `logo/`.

Файлы:
- `sovremennik-logo-on-purple.png` — логотип на фирменном фиолетовом фоне;
- `sovremennik-logo-transparent.png` — версия с прозрачным фоном, полученная из предоставленного исходного изображения.

### Запрещено

- менять фирменные цвета логотипа;
- искажать пропорции;
- растягивать или сжимать по одной оси;
- добавлять тени, свечения и обводки;
- менять взаимное расположение знака и текста;
- самостоятельно перерисовывать логотип;
- заменять логотип визуально похожей версией.

## Визуальный стиль

Базовые принципы:
- чистая современная композиция;
- достаточное количество свободного пространства;
- белый или фирменный фиолетовый фон;
- акценты бирюзового, голубого и светло-фиолетового цветов;
- лаконичная графика;
- визуальная лёгкость.

Не использовать без отдельного указания:
- градиенты;
- тяжёлые фильтры;
- случайные дополнительные цвета;
- декоративные эффекты, не относящиеся к фирменному стилю;
- визуальный стиль ГК САР вместо стиля ЖК «Современник».

## Главное правило редактирования макетов

Если пользователь пишет **«оставь всё неизменным, только…»**, необходимо менять только явно перечисленные элементы.

Нельзя самовольно:
- менять композицию;
- менять цвета;
- менять шрифты;
- менять размеры и положение других элементов;
- заменять фотографии;
- менять кадрирование;
- добавлять новые элементы.

При удалении элемента необходимо аккуратно восстановить фон на его месте.

## Примечание по векторному логотипу

В текущем комплекте нет оригинального векторного файла логотипа (SVG/AI/EPS), потому что исходником было предоставлено растровое изображение.  
Не создавать «примерный» SVG автоматически. Если появится официальный векторный логотип из брендбука, его нужно добавить в эту папку и считать основной версией.
