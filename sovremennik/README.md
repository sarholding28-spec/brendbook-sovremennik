# Brand assets — ЖК «Современник»

Готовая папка для загрузки в GitHub.

## Рекомендуемый путь в репозитории

`brands/sovremennik/`

## Состав

- `BRAND_GUIDE.md` — правила использования фирменного стиля
- `brand-reference.jpg` — исходный визуальный референс
- `logo/sovremennik-logo-on-purple.png` — логотип на фирменном фоне
- `logo/sovremennik-logo-transparent.png` — логотип с прозрачным фоном
- `colors/palette.json` — точные HEX-цвета
- `colors/palette.css` — CSS-переменные
- `colors/palette.png` — визуальная палитра

После загрузки в GitHub достаточно передавать ссылку на папку `brands/sovremennik/`.
